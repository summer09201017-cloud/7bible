■ 怎麼跑 / 測 / 建置
  npm install
  npm run dev       本機開發 http://localhost:5173
  npm run build     產出 dist/
  npm run lint      ESLint（目前全綠）
  npm run preview   預覽 build http://localhost:4173
  （沒有 npm test；此專案無自動化測試。驗證靠 lint + build + 手動點。）
  Windows：雙擊「啟動本機網站.bat」跑 preview 並自動開瀏覽器。

■ 部署 (重要)
  Netlify 已連 GitHub 自動部署 —— push 到 main 分支就自動 build + 上線，
  不需要手動 netlify deploy。
  site id：6d0419a7-7222-4c5e-a9c3-610b0a7cb3a7
  冒煙驗證線上是不是新版（帶 ?bust= 破 CDN 快取）：
    curl -s "https://7bible.netlify.app/?bust=$(date +%s)" | grep -o 'assets/index-[^"]*\.js'
    再抓那個 bundle grep 關鍵字（例如「串珠」「讀經足跡」）確認上去了。
  改了殼層（sw.js / index.html / 資料結構）務必 bump sw.js 的 CACHE_NAME，
  否則手機吃舊快取。

■ 本機地雷 (踩過的雷)
  0. **本機 dist/ 不可信**（0809 審查抓到 dist 停在 v12 而線上 v16）：Netlify 由 git 觸發
     自動 build，本機 dist 只是上次手動 build 的殘骸——**絕對不要拖拉 dist 部署**，
     手滑一次=整站倒退好幾版。dist 已在 .gitignore；驗證線上一律 curl 帶 ?bust=。
  1. Windows + Node 24 的 vite build 會偶發無聲中斷/exit 127（rmSync 被 OS 砍）。
     解法：rm -rf dist 後重跑 npx vite build 通常就過；用產物 hash 有沒有變
     來確認是真的重建，不要只看指令有沒有回傳。
  2. App.jsx 的 TDZ 陷阱：useEffect 的 deps 若引用「後面才宣告的 const」，
     整個 app 會 unmount（手機一片綠、桌面常被舊 bundle 蓋住）。
     宣告順序固定：useState → useRef → 簡單 effect → useCallback → 用到 callback 的 effect。
  3. 別用 window.alert 當一般提示（已改用 toast，showToast()）。

■ 檔案在哪
  src/App.jsx        幾乎全部（~2300 行，刻意單體）。所有元件、狀態、樣式(inline S 物件)。
  src/api.js         fetchBible()（查詢路由 + 搜尋）、loadXref()（串珠懶載入）、VERSIONS。
  src/bible_books.js bookMap（66 卷）、findLocalAbbrev()。
  public/data/*.json 8 譯本全文（thiagobodruk 格式），NIV/ 按卷。
  public/data/structure.json  輕量書卷/章/節數（5KB，啟動用）。gen 見 scripts/gen-structure.mjs
  public/data/xref/  串珠，每卷一檔。gen 見 scripts/gen-xref.mjs（吃 cross_references.txt 路徑）
  public/sw.js       離線快取 SW（改殼層要 bump CACHE_NAME）。
  CLAUDE.md          給 AI 的完整架構 + gotcha 清單（最權威）。
  README.md          給老師/牧者的使用說明。
  roadmap.md         已完成 / 待做（CP 值排序）/ 刻意不做。
  AGENTS.md          給 Codex agent 的版本（內容對齊 CLAUDE.md）。
